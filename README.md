# Bingo18

Trang thống kê và dự đoán Bingo18 (Vietlott): https://tungtran98.github.io/bingo18/

- `index.html`: trang chính, tự cập nhật kết quả mỗi 3 giây từ xosohomnay.com.
- `scripts/fetch-data.js` và `.github/workflows/pages.yml`: GitHub Actions chạy khoảng 5 phút một lần, gom kết quả mới từ xosohomnay.com và vietlott.vn vào `data.json` để trang bù các kỳ bị thiếu.

Kết quả Bingo18 là ngẫu nhiên; trang chỉ để tham khảo, không đảm bảo trúng thưởng.
